## 🧑‍💻 About Me

I'm a **Full-Stack Developer** specializing in **Node.js**, **NestJS**, **React**, and **TypeScript**, passionate about building scalable, maintainable, and high-performance applications — from database to UI.

On the **backend**, I design **RESTful APIs**, **authentication & authorization** (JWT, RBAC), **real-time systems** with WebSockets, **advanced MongoDB aggregation pipelines**, **PostgreSQL with TypeORM**, and write **unit tests with Jest**.

On the **frontend**, I craft modern, responsive UIs with **React**, **Redux Toolkit**, **React Query**, **Tailwind CSS**, custom **Hooks**, and clean component architecture.
